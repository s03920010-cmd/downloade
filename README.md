# بات دانلودر اینستاگرام (RadRub)

امکانات: دانلود ویدیو (با انتخاب کیفیت)، دانلود صدا، دانلود عکس پست.
فقط لینک‌های عمومی اینستاگرام پشتیبانی می‌شوند.

## نصب
    python -m pip install -r requirements.txt

## اجرا
PowerShell:  $env:RUBIKA_BOT_TOKEN="توکن_بات"
CMD:         set RUBIKA_BOT_TOKEN=توکن_بات
    python bot.py

سقف حجم دانلود: ۱۰۰ مگابایت (MAX_FILE_BYTES در bot.py).
